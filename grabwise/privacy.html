2. Data We Collect and How We Use It

A. Local Device Data (Default Standalone Mode)

In the default Standalone (Offline) Mode, all your data is stored entirely on your device's local storage using SharedPreferences. This includes:

  • Grocery items, quantities, units, categories, custom notes, and purchase statuses.
  • Preferred store names and brand preferences.
  • Purchase history logs and frequency counters for the "Buy Again" feature.
  • App settings: language selection (English, Tamil, Bilingual), visual theme, Elder Mode toggle, and auto-cleanup duration.

WiselyRise servers never receive, process, or store this locally held data.

B. Cloud Sync Data (Opt-In Mode)

If you voluntarily enable Cloud-Shared Mode to synchronize your list with family members, the following minimal data is transmitted and stored in Google Firebase Cloud Firestore:

  • Household Record: A randomly generated household ID, a user-assigned household display name (e.g., "Home"), and a 6-character join invite code.
  • Shopping List Items: Item names, quantities, category tags, brand notes, and purchase status flags.
  • Anonymous Authentication Token (UID): A Firebase Authentication anonymous UID used exclusively to manage read/write permissions for that household document. This UID contains no email address, phone number, real name, or device hardware identifiers.
  • Custom Item Photos (Optional): If you attach a photo to an item, the image is compressed on-device and stored in Firebase Storage scoped strictly to your household ID.

C. Voice / Microphone Access

GrabWise includes an optional voice dictation feature for hands-free grocery entry:

  • Microphone permission is requested only when you actively tap the microphone icon.
  • Speech-to-text transcription is handled entirely by your device's native speech recognition framework (Google Speech Recognition on Android, Apple Dictation on iOS).
  • WiselyRise does not record, upload, retain, or process your raw audio recordings in any form.

3. Permissions Requested

Permission Platform Why It's Needed
INTERNET Android, Web Enables real-time synchronization with household members when Cloud Sharing is voluntarily enabled.
RECORD_AUDIO Android, iOS Powers on-device voice dictation for adding grocery items hands-free using the microphone button.
RecognitionService Android Queries the device's built-in speech recognizer to convert spoken words to text on-device.

GrabWise does NOT request access to your Contacts, GPS Location, SMS messages, Call Logs, Camera, or any other device sensor.

4. Third-Party Service Providers

GrabWise uses trusted infrastructure services solely for technical backend hosting of the opt-in cloud synchronization feature:

  • Google Firebase Authentication — Anonymous session tokens for household document access control.
  • Google Cloud Firestore — Real-time database hosting for shared household lists.
  • Firebase Storage — Secure asset storage for user-uploaded custom item photos.
  • Firebase Hosting — Static web application delivery for grabwise.web.app.

Google processes this data as a technical processor under robust industry security certifications (ISO 27001, SOC 1/2/3). We have no other third-party data partnerships, analytics vendors, or advertising networks.

5. Data Retention & User Control

  • Auto-Cleanup: You control how long purchased items stay in the list — Manual, 24 Hours, 48 Hours (default), or 7 Days.
  • Local Data Erasure: Clear all local data at any time via Settings → Reset Household / Clear Data.
  • Cloud Data Deletion: The household organizer can permanently delete all shared list data and the household document from Firebase Firestore directly from within the app settings.

6. Children's Privacy

GrabWise is a general-audience household utility. We do not knowingly collect personal identifiable information from children under 13 (or under 16 in applicable jurisdictions). Since GrabWise requires no user registration, sign-in, or personal identity information, no child's personal data is gathered by our systems.
